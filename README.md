# مؤسسة طريق القمة — برنامج المحاسبة

برنامج محاسبة بالعربي، يشتغل من المتصفح على الموبايل أو الكمبيوتر.

## المزايا
- **الصفحة الرئيسية**: أربع أزرار كبيرة: فاتورة شراء، فاتورة بيع، سند قبض، سند صرف.
- **فواتير بيع وشراء**: طريقة الدفع **نقدي** أو **ذمم**. فواتير الذمم بس بتظهر بكشف الحساب، والنقدي بيروح على الصندوق.
- **العملاء لحال والموردين لحال**: لكل قسم فواتيره وسنداته وكشف حسابه.
- **سندات قبض** (من العملاء) و**سندات صرف** (للموردين).
- **كشف حساب عميل / مورد**: مع فلترة حسب التاريخ ورصيد متراكم وطباعة.
- **الصندوق**: الفواتير النقدية والسندات.
- **ضريبة المبيعات**: نسبة لكل فاتورة (افتراضياً 16%)، أسعار شاملة أو غير شاملة، وكشف ضريبة فيه ضريبة المبيعات والمشتريات والدفعات والصافي المستحق. كشوفات العملاء والموردين بتعرض إجمالي الفاتورة بس.
- **نسخ احتياطي**: تنزيل كل البيانات بملف واسترجاعها.

## التشغيل
افتح ملف `index.html` بالمتصفح، أو من GitHub Pages.

## المزامنة بين الأجهزة
البرنامج بيستعمل Firebase (Firestore + Authentication) لحفظ البيانات على السيرفر ومزامنتها بين كل الأجهزة.
إعدادات المشروع موجودة بملف `firebase-config.js`. إذا كانت `null` البرنامج بيشتغل على الجهاز بس.

قواعد Firestore المقترحة (بدّل الإيميل بإيميل حساب المؤسسة):

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /shops/{shop}/{document=**} {
      allow read, write: if request.auth != null
        && request.auth.token.email in ['YOUR-EMAIL@example.com'];
    }
  }
}
```
