# محاسبة المحل

برنامج محاسبة بسيط لمحل تجاري، بالعربي، يشتغل من المتصفح على الموبايل أو الكمبيوتر.

## المزايا
- **فواتير بيع وشراء**: نقدية أو على الحساب (دين)، مع خصم ودفعة جزئية وطباعة.
- **الزبائن والموردين**: مع رصيد افتتاحي ورصيد حالي لكل واحد.
- **سندات قبض وصرف**: لتسجيل المبالغ اللي بتستلمها من الزبائن أو بتدفعها للموردين.
- **كشف حساب**: لأي زبون أو مورد، مع فلترة حسب التاريخ ورصيد متراكم وطباعة.
- **الصندوق**: حركة الكاش الداخل والطالع ورصيده.
- **الأصناف والمخزون**: الكمية الموجودة بتتحسب تلقائياً من الفواتير.
- **نسخ احتياطي**: تنزيل كل البيانات بملف واسترجاعها.

## التشغيل
افتح ملف `index.html` بالمتصفح، أو انشره على GitHub Pages.

> البيانات محفوظة بالمتصفح على نفس الجهاز. خذ نسخة احتياطية من صفحة الإعدادات بشكل دوري.
