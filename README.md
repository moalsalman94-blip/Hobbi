# مؤسسة طريق القمة — برنامج المحاسبة

برنامج محاسبة بالعربي، يشتغل من المتصفح على الموبايل أو الكمبيوتر.

## المزايا
- **الصفحة الرئيسية**: أربع أزرار كبيرة: فاتورة شراء، فاتورة بيع، سند قبض، سند صرف.
- **فواتير بيع وشراء**: طريقة الدفع **نقدي** أو **ذمم**. فواتير الذمم بس بتظهر بكشف الحساب، والنقدي بيروح على الصندوق.
- **العملاء لحال والموردين لحال**: لكل قسم فواتيره وسنداته وكشف حسابه.
- **سندات قبض** (من العملاء) و**سندات صرف** (للموردين).
- **كشف حساب عميل / مورد**: مع فلترة حسب التاريخ ورصيد متراكم وطباعة.
- **الصندوق**: الفواتير النقدية والسندات.
- **الأصناف والمخزون**: الكمية بتنحسب تلقائياً من الفواتير.
- **نسخ احتياطي**: تنزيل كل البيانات بملف واسترجاعها.

## التشغيل
افتح ملف `index.html` بالمتصفح، أو من GitHub Pages.

> البيانات محفوظة بالمتصفح على نفس الجهاز. خذ نسخة احتياطية من صفحة الإعدادات بشكل دوري.
